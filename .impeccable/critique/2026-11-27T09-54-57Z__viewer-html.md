## Priority issues
- [P1] Header height + wrapping (20–44% of viewport; ~99% at 200% browser zoom on 1366x768). Fix: single 40px nowrap bar with menus (favorites in URL dropdown, devices menu, Tools/Overlays menus, zoom stepper), 28px breakpoint ruler, floating compare dock, 26px single-row card heads, focus mode.
- [P1] Red semantic overload. Fix: red only for errors + primary Go; neutral on-states.
- [P1] postMessage spoofing by framed pages: HTML/CSS injection into overflow panel (viewer.js:513,519), clicks/typing into B, data: URLs to tabs.create (viewer.js:832), password values mirrored to B with '*' (viewer.js:94,1004; content.js:262). - [P1] render() tears down and reloads all iframes on tab switch/pin/add/remove (viewer.js:144) — loses scroll, forms, Edit changes. Fix: reconcile by device id.
- [P1] Breakpoint slider/width input lose keyboard focus ~300ms after each change (renderBp innerHTML rebuild via rescan->media). WCAG 2.1.1/2.4.3.
- [P2] Unlabeled/misleading icons; #5c5c64 2.85:1 and #55555c 2.69:1 text; no frame loading/error states; blank first run.
